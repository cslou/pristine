# Changelog

All notable public changes to Pristine will be documented in this file.

This project follows semantic versioning once it reaches `1.0.0`. Before `1.0.0`, minor versions may include breaking API changes, but breaking changes must be called out here with migration notes.

## [Unreleased]

### Added

- Public alpha documentation for installation, quickstart usage, privacy threat model, contribution workflow, release checks, and supported root exports.
- Deterministic public CI and local verification commands for package, docs, smoke, integration, and e2e checks.

### Changed

- Public onboarding now describes the current source-pointer SDK surface instead of the removed raw-transcript ownership architecture.

### Security

- Public-release preparation includes dependency audit, package artifact verification, and repository secret/history audit evidence.

### Release status

- Actual npm publishing remains out of scope for Sprint 025.
