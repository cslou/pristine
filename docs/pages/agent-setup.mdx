# Agent setup prompts

Use this section when you want a coding agent to wire Pristine into a local harness. Start with the SDK quickstart, then copy the setup prompt for the capability you want the agent to configure.

## Copy-paste prompts

- [Memory setup prompt](/quickstart#memory-setup-prompt) — ask a coding agent to wire Pi JSONL indexing, `pristine_recall`, and source-pointer inspection.
- [Privacy setup prompt](/quickstart#privacy-setup-prompt) — ask a coding agent to add redaction, local reveal, and output scrubbing boundaries.

## Pi-dev

For Pi development environments, use the [Pi-dev integration guide](/pi-dev) and the [`examples/pi-dev` runbook](https://github.com/getlou-gh/pristine/tree/main/examples/pi-dev). The guide explains how Pristine indexes Pi JSONL session history, recalls source pointers, and routes inspection back to the authoritative session source.

## SDK baseline

If the harness is not Pi, start from the [quickstart](/quickstart) and [API reference](/api). The host application owns the integration boundary and decides which files, sessions, or records are safe to index.
