# API

## `Pristine`

- `Pristine.create(config?)` creates a local client.
- `store(chunks, { projectId })` stores source-owned text and metadata.
- `recall(query, { projectId, limit? })` returns ranked semantic matches.
- `forget(chunkIds, { projectId })` removes indexed chunks.
- `status(projectId)` returns the stored chunk count.
- `dispose()` closes client-owned resources.

The package also exports `createDatabase`, the `Embedder` contract, source chunk types, and low-level source-index primitives for advanced local integrations.
