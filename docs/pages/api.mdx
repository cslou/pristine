# API

The public SDK surface centers on `Pristine` plus intent-named primitives. Use this page as Reference material after reading the conceptual [Memory](/memory), [Privacy](/privacy), and [Pi-dev integration](/pi-dev) guides.

## Client creation

```ts
import { Pristine } from '@pristine/sdk';

const pristine = await Pristine.create();
```

`Pristine.create` accepts optional configuration for local paths, an injected database, an injected embedder, and deterministic privacy classification.

## Memory API

### `store(chunks, { projectId })`

Stores selected source text with stable IDs and returns stored memory records. Each chunk can include source metadata such as `chunkId`, `sourceKind`, `sourceUri`, `entryId`, line numbers, timestamp, and custom metadata. See [Memory](/memory) for the source-of-truth model.

### `recall(query, { projectId, limit? })`

Searches a project by semantic query and returns ranked memory hits. Returned hits include the stored source metadata and a score.

### `forget(chunkIds, { projectId })`

Deletes stored chunks by ID within one project and returns a deletion count.

## Privacy API

### `detect`, `classify`, and `redact`

The canonical privacy flow is primitive-first: `detect` finds local candidates with `sourceSpan` metadata, `classify` sends sanitized candidate markers and safe `hint` metadata to caller-owned `classifierCallback` policy, and `redact` stores confirmed `{ sourceSpan, type, label? }` spans in the local vault while returning model-safe text plus `sensitiveRef`, placeholder, original `sourceSpan`, and output `redactedSpan` metadata. The package root exports the low-level `redact` function for callers that inject vault/key managers; `Pristine.redact(text, confirmed, userId)` uses the client's configured local vault and key managers. The SDK does not implement a hosted classifier or bundled LLM classifier; if you want deterministic regex-only behavior, implement it as your classifier callback or harness policy.

`classify` can return `secret`, `not_secret`, or `uncertain`. The harness owns uncertain handling and any policy that maps secret decisions to confirmed redaction inputs. Raw candidate values are not sent to the callback; the request uses `[CANDIDATE:<id>]` markers and raw-value-free hints.

The migration for new integrations is primitive-first `detect` → `classify` → `redact`, then use `reveal`, `resolveSensitive`, and `scrubOutput` in trusted local flows. See [Privacy](/privacy) for threat-model responsibilities.

### `reveal(redactedText, userId)`

Restores known redaction placeholders for a local user when vault and key access allow it.

### `listSensitive(userId, options?)`

Lists metadata-only summaries for locally vaulted sensitive values. Results include placeholder refs, `sensitiveType` as the canonical machine type, generated labels, optional caller-provided aliases, and timestamps; they do not include plaintext secret values. When `limit` is omitted, the SQLite vault applies a bounded default of 100 summaries. Options support `limit`, `sensitiveType`, `createdFrom`, and `createdTo`.

### `getSensitive(userId, sensitiveRef)`

Returns one metadata-only summary for a sensitive placeholder ref, or `null` when no entry exists for that user.

### `updateSensitive(userId, sensitiveRef, input)`

Updates caller-owned visible metadata for a sensitive placeholder ref. The current input supports `alias`, where `null` or an empty string clears the alias. Caller-managed aliases must never contain plaintext secrets. Aliases are returned by `listSensitive` and `getSensitive`, so callers should display `alias ?? label` while keeping `sensitiveType` as the canonical machine type. Missing refs throw `SensitiveNotFoundError`.

### `deleteSensitive(userId, sensitiveRefs)`

Deletes vaulted entries by exact placeholder ref and returns `{ deletedCount, missingSensitiveRefs }`. Invalid caller input throws `InvalidArgumentError`.

### `resolveSensitive(userId, sensitiveRef)`

Returns the plaintext value for one sensitive placeholder ref when local vault and key access allow it. This is a privileged local operation; missing refs throw `SensitiveNotFoundError`.

### `scrubOutput(text, allowlist?)`

Removes sensitive values from output text before tool results or generated output are written back into agent/model context or session history. The second parameter is named `allowlist` in the current TypeScript signature for compatibility, but its values are scrubbed from output; pass revealed or sensitive values that must be removed.

## Root exports

The package root is the supported import surface. It exports the SDK client, domain errors, database helper, public types, and a small set of low-level source-index primitives for advanced local integrations.

### Supported value exports

| Export                             | Purpose                                                                           |
| ---------------------------------- | --------------------------------------------------------------------------------- |
| `Pristine`                         | Main local SDK client.                                                            |
| `createDatabase`                   | Create or open a SQLite database with Pristine's sqlite-vec loading behavior.     |
| `detect`                           | Find raw-value-free sensitive candidates with `sourceSpan` and safe `hint` data.  |
| `classify`                         | Build sanitized marker context and invoke a caller-owned classifier callback.     |
| `redact`                           | Store confirmed spans in the local vault and return placeholder metadata.         |
| `AppError`                         | Base domain error class.                                                          |
| `ConfigError`                      | Configuration error class.                                                        |
| `EmbedderError`                    | Embedder failure class.                                                           |
| `InvalidArgumentError`             | Public validation error class.                                                    |
| `SensitiveNotFoundError`           | Missing sensitive placeholder error for privileged resolve/update flows.          |
| `SOURCE_CHUNK_METADATA_JSON_LIMIT` | Source chunk metadata size limit.                                                 |
| `SOURCE_CHUNK_TEXT_LIMIT`          | Source chunk text size limit.                                                     |
| `SourceChunkStore`                 | Supported low-level source-index store for advanced local integrations and tests. |
| `buildSourceChunkVectorDdl`        | Builds source chunk vector table DDL for the configured dimension.                |
| `initSourceChunkTables`            | Initializes source chunk tables owned by the source-index module.                 |
| `normalizeSourceChunkInput`        | Validates and normalizes source chunk input.                                      |

## Internal imports

The package root does not export raw conversation storage, ingest queues, worker drains, SQL searchers, provider SDK clients, or benchmark-only helpers. Consumers should compose the supported source chunk and privacy primitives instead of importing internal paths. Harness-specific setup should start from [Integrations](/pi-dev) and [Examples](/examples).
