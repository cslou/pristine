# Pristine

Pristine is a minimal local SDK for agent memory and privacy.
It provides the essential building blocks for searchable local recall, redaction, reveal, and output scrubbing.

## Minimal by design

Those building blocks cover two local capabilities:

- **Memory:** searchable local recall over stored content, with references back to the original.
- **Privacy:** local redaction, trusted local reveal, and output scrubbing before secrets enter model context or session history.

Pristine does not require a hosted service or prescribe your harness workflow. Your application decides what to index, what to redact, when to recall, when to reveal, and how to compose these primitives into tools, extensions, skills, or agents.

## What Pristine gives your agents

- **Local-first memory:** index local conversations, notes, files, and records, recall them by semantic search, and inspect the source reference directly.
- **Secret handling:** replace secrets with placeholders before text enters agent/model context, reveal originals only inside trusted local tool runners, and scrub tool results or generated output before they are written back into context or session history.
- **Harness-friendly primitives:** Pristine provides the building blocks for customizing memory and privacy solutions for agent harnesses such as Pi.
