# Pristine

Pristine is local-first memory and privacy for agent harnesses. It gives TypeScript applications a small SDK for source-pointer memory, local redaction/reveal, and output scrubbing without requiring a Pristine server.

## What Pristine gives you

- **Local-first memory:** store chunks locally, recall them by semantic query, and inspect the source pointer before acting on the result.
- **Privacy boundaries:** redact sensitive text before agent/model context, reveal locally when policy allows, and scrub generated output before it crosses a boundary.
- **Harness-friendly primitives:** integrate Pristine into Pi or another host harness while the host remains the source of truth for files, sessions, and records.
- **Typed SDK:** use the `Pristine` client from a strict TypeScript ESM package.
