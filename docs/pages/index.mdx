# Pristine

Pristine is a local-first privacy and source-pointer memory SDK for TypeScript. It helps applications and agents store useful memory locally, recall it by semantic query, and trace results back to their source.

## Why Pristine

- **Local-first by default:** no Pristine server is required.
- **Privacy primitives included:** redact sensitive text, reveal it locally when allowed, and scrub generated output before it crosses a boundary.
- **Source-pointer memory:** recall results include metadata that points back to the source record, file, session, or line that produced the memory.
- **TypeScript SDK:** strict ESM package with typed public APIs.
