# Memory

Pristine memory is local, source-pointer memory for applications and agent harnesses. The SDK stores searchable chunks with source metadata so recall can point back to the record, file, session, or line that produced the memory.

## Source-owned by design

Pristine stores an index for recall; your host application remains the source of truth. Keep authoritative records in your own files, sessions, database, or harness history, and use Pristine recall results as pointers back to those records.
