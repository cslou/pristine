# Pi-dev integration

Pristine includes a reference Pi-dev integration for indexing Pi JSONL session history and recalling likely-relevant source pointers.

Start with the integration runbook:

- [`examples/pi-dev/README.md`](../../examples/pi-dev/README.md)

The canonical Pi recall tool is `pristine_recall`. Use it for semantic discovery, then inspect exact JSONL context with the `search-session-history` skill and ordinary file tools.
