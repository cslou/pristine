# Secure, redact, reveal

Use Pristine privacy APIs to protect sensitive text before it enters an agent or model context and to restore it only in approved local flows.

## secureAndRedact

`secureAndRedact` detects sensitive values, stores encrypted originals in the local vault, and returns redacted text with placeholders.

## scrubOutput

`scrubOutput` scans generated output before it crosses a sensitive boundary. Use it as a final safety check for text produced by tools, agents, or models.

## reveal

`reveal` restores placeholders when the caller has local access to the vault and keys and the application policy allows restoration.
