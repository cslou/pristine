# Quickstart

```ts
import { Pristine } from '@pristine/sdk';

const pristine = await Pristine.create();
const projectId = 'local-project';

await pristine.store(
  [{
    chunkId: 'note-1',
    text: 'Pristine keeps project memory local.',
    sourceKind: 'note',
    sourceUri: 'file:///notes/project.md',
  }],
  { projectId },
);

const hits = await pristine.recall('project memory', { projectId, limit: 3 });
await pristine.forget(['note-1'], { projectId });
await pristine.dispose();
```

Use returned source pointers to inspect authoritative context before relying on a recalled result. For Pi integration, see [Pi-dev](/pi-dev).
