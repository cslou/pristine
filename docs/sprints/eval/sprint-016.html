Key Changes — searcher module + RRF fusion

Searcher module structure

src/memory/searcher/
└── index.ts (922 lines)
    ├── Public types     — SearchFilters, WindowHit, MessageHit, SessionHit, HybridHit, HybridSource
    ├── Constants        — MAX_LIMIT (1000), VEC_DIM (768), distanceToScore, bm25ToScore
    └── createSearcher() factory
        ├── Hoisted prepared statements (resolveMessageIdsBatch, roleMatchesBatch)
        ├── buildCandidateSql       — filter-first narrowing
        ├── vectorSearch            — vec0 KNN over vec_windows
        ├── ftsSearch               — bm25 over messages_fts
        ├── sessionVectorSearch     — vec0 KNN over vec_sessions
        └── hybridSearch            — Promise.allSettled + RRF (k=60)

src/memory/retriever/ranking.ts (gained reciprocalRankFusion + RRF_DEFAULT_K)

RRF fusion formula (Cormack et al. 2009)

score(d) = Σᵢ 1 / (k + rankᵢ(d))     where k = 60

Each leg contributes one term per document it ranked.
Documents in multiple legs accumulate higher fused scores.
Tie-breaking: stable first-seen order across input lists.

Filter-first candidate-set EXPLAIN QUERY PLAN

EXPLAIN QUERY PLAN
SELECT c.id FROM conversations c
WHERE c.project_id = ? AND c.created_at >= ?;

QUERY PLAN
`--SEARCH c USING INDEX ix_conversations_project_started (project_id=? AND created_at>?)

Index hit on (project_id, created_at DESC) — no full scan. Existing ix_conversations_project_started from sprint-014 covers the hot path; no new indexes needed.

storeAsync — before / after

Before (broken)

public storeAsync(conversation, userId): string {
  return this.ingestQueue.enqueue(
    conversation, userId,
  );
  // ↑ writes task_type='extract-conversation'
  // → processNext throws (orchestrator deleted
  //   in sprint-013) — corpus stays empty.
}

After

public storeAsync(
  conversation, userId, projectId?,
): string {
  if (this.indexer === null) throw …;
  return this.db.transaction((): string => {
    const id = this.conversationStore
      .addEmptyConversation(userId, conversation, projectId);
    this.indexer.ingest(conversation, {
      projectId, conversationId: id,
    });
    return id;
  })();
}

HybridHit discriminated union

type HybridHit =
  | { kind: 'window';  conversationId; windowIndex; messageIds; score; source }
  | { kind: 'message'; conversationId; messageId; score; source; snippet? }
  | { kind: 'session'; conversationId; score; source };

type HybridSource = 'vector' | 'fts' | 'session' | 'both';

// Stable ids for fusion (disjoint prefixes prevent collision):
//   window:{conversationId}:{windowIndex}
//   message:{messageId}
//   session:{conversationId}
