# Examples

Pristine examples are reference implementations that show one way to compose the SDK primitives for a specific host environment. They are optional: normal SDK usage does not require copying anything from this directory.

## Available examples

| Path | Host | Purpose |
| --- | --- | --- |
| [`pi-dev/`](./pi-dev/) | Pi coding agent | Pi JSONL indexing, vector search, and source-pointer session-history inspection. |

Each example group owns its install and verification instructions in its local README.
